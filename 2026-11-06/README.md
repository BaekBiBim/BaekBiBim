# Git과 GitHub 실습 자료

이 폴더에는 Git과 GitHub 교육에서 다룬 브랜치, 병합 및 충돌 해결 실습 자료가 들어 있습니다. `1.txt`부터 `5.txt`까지는 실습용 파일이며 일부는 비어 있습니다.

## 학습 내용

- `git status`로 현재 브랜치와 변경 상태 확인
- 브랜치를 만들고 전환해 별도 작업 수행
- `git merge`로 브랜치를 합치고 충돌을 해결
- GitHub CLI(`gh`)로 원격 저장소 및 이슈 생성
- 변경 사항을 커밋하고 원격 저장소에 푸시
- Pull Request로 브랜치 변경 사항을 검토

자세한 연습 문제는 [execise.md](execise.md)를 참고하세요. 아래 명령어들은 기존 작업에 영향을 줄 수 있으므로 **별도의 연습용 저장소**에서 실행하세요.

## 기본 흐름

```bash
git status
git add <파일명>
git commit -m "변경 내용 설명"
git push origin <브랜치명>
```

충돌이 생기면 파일의 충돌 표시를 확인하고 원하는 내용을 남긴 다음 `git add <파일명>`으로 해결을 표시합니다. 이후 `git commit`으로 병합을 완료합니다. 작업 중인 변경 사항을 임의로 삭제하거나 초기화하지 않도록 주의하세요.
